抢单策略

这些参数控制 auto 模式下的抢单行为。notify / confirm 模式不受影响。

≥ 此分数才会自动拍下（在 评估权重 设置）
≥ 此分数会推送给用户确认

任务级模式

每个任务可独立设置执行模式（在 任务管理 中）：

  • 🔔notify 仅推送通知，不抢单（最安全）
  • ✋confirm 推送后等待用户确认（推荐日常）
  • ⚡auto 全自动抢单（仅在 auto_buy_score 足够高时使用）

安全护栏

建议：

  • auto_buy_score ≥ 80 才启用 auto 模式
  • 单日抢单数量上限：在 buyer_config.py 中配置（待 UI 化）
  • 支付前暂停：默认开启（在 dashboard 可手动接管）
⚠️ 谨慎使用 auto 模式：自动拍下会立即锁定你的资金，请确认已充分测试。
