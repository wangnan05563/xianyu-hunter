## §1 F-02 全局快捷键 + Command Palette（P0）

### 实现内容
- **Ctrl+K** 唤起 Command Palette 模态层
- **14 条内置命令**：导航（dashboard/tasks/orders/evaluations/timeline/config/logs）+ 操作（新建任务/暂停全部/恢复全部/通知中心/错误日志/帮助）
- **模糊搜索**：字符包含 + 权重排序（标题命中 > hint 命中）
- **键盘导航**：↑↓ 切换 / Enter 执行 / Esc 关闭
- **g+二次键**：Vim 风格导航（g d → dashboard 等）
- **批量操作**：`_batchControl(action)` 调用 `/api/tasks/batch-control` 实现"暂停全部/恢复全部"

### 关键修复
- **x-teleport 不渲染**：Alpine.js `x-teleport="body"` 在 Playwright headless 中不渲染内容，改为直接放在 `.app` div 内用 `x-show` + `z-index:200`

## §4 F-07 时间趋势可视化增强（P1）

### 实现内容
- **sparkline 可点击展开**：点击 4 张统计卡 → 弹出大图折线 Modal
- **7d/30d/90d 时间范围**：后端 API 扩展支持 `range_hours=720/2160`
- **大图折线**：800×300 SVG + Y 网格 + X 时间标签 + hover tooltip
- **参考线**：
  - eval_score 图：中位数基线（黄色虚线）
  - success_rate 图：50% 告警阈值（红色虚线）

### 关键修复
- **`_parse()` TypeError**：`_build_trend_series` 中的 `_parse` 函数假设 `ts` 是字符串，但 ORM 返回的 `created_at` 可能是 `datetime` 对象，添加 `isinstance(s, datetime)` 检查

### 涉及文件
- [api_stats.py](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/web/routes/api_stats.py)：range_hours 扩展 + _parse 修复
- [dashboard.html](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/web/templates/dashboard.html)：趋势大图 Modal + renderTrendChart + _renderTrendRefLines
