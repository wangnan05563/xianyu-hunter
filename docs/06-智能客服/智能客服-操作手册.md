# 智能客服操作手册

## 概述

智能客服是闲鱼猎人系统的对话式智能助手，通过自然语言对话帮助用户理解系统功能、掌握操作流程、解决使用问题。后端基于 RAG（检索增强生成）+ AGENT（智能代理）架构，回答始终基于项目最新文档，避免幻觉；前端采用 SSE 流式输出，逐 token 显示回答。

**入口位置**：

| 项 | 内容 |
|----|------|
| 菜单路径 | 侧边栏「其他」→「智能客服对话」 |
| 菜单图标 | `MessageOutlined` |
| 路由 | `/chatbot` |
| 快捷键 | `g` 然后按 `m`（500ms 内） |
| 配置页路由 | `/config/chatbot`（侧边栏「客服配置」） |
| 前端实现 | `frontend/src/pages/Chatbot/index.tsx` |

> 智能客服仅回答与闲鱼猎人系统使用相关的问题（功能咨询、配置调优、故障排查、操作流程等），不回答闲鱼平台规则、其他产品、闲聊等超范围问题。

## 核心特性

- **SSE 流式对话**：采用 `fetch + ReadableStream` 实时推送 token，回答逐字显示，可中途「停止生成」
- **消息撤回 2 分钟**：用户消息发送后 2 分钟内可撤回，撤回后 AI 不再引用该内容
- **多模态图片**：支持点击/粘贴/拖拽上传图片（最多 4 张、单张 5MB），AI 可解析图片内容
- **工具调用**：5 个内置工具（任务状态/评估分数/配置值/错误日志/帮助文档），实时查询系统数据
- **转人工支持**：5 类触发条件自动转人工，提供联系方式与「复制会话记录」按钮（自动脱敏）
- **会话收藏与搜索**：星标收藏会话置顶显示，关键词搜索会话标题与消息内容，附搜索历史小药丸
- **快捷回复与引导卡**：空会话显示欢迎语 + 4 张热门功能卡 + 5 个常见问题入口；输入区上方显示快捷回复 Chip
- **帮助中心**：弹窗形式展示使用指南、常见问题、快捷键、版本信息
- **1-5 星评分**：替代二值点赞点踩，4-5 星为 positive，1-3 星为 negative，可附问题分类与文字反馈

## 基本操作

| 序号 | 操作 | 触发方式 | 说明 |
|------|------|----------|------|
| 1 | 进入智能客服 | 侧边栏「其他」→「智能客服对话」 或 按 `g` 后 500ms 内按 `m` | 跳转 `/chatbot`，默认加载最近一个会话 |
| 2 | 新建会话 | 点击左侧「+ 新建会话」按钮 | 创建空会话，显示引导卡（首次）或空状态 |
| 3 | 切换会话 | 点击左侧会话列表项 | 加载该会话历史消息，自动滚动到底部 |
| 4 | 删除会话 | 会话项右侧 🗑 图标 → 二次确认「删除」 | 删除会话及所有消息与反馈，不可恢复 |
| 5 | 收藏会话 | 会话项右侧 ☆ 图标 | 切换收藏状态，收藏会话自动置顶显示 |
| 6 | 搜索会话 | 左侧搜索框输入关键词 | 400ms 防抖搜索会话标题与消息内容，记录搜索历史 |
| 7 | 仅看收藏 | 搜索框右侧 ☆ 按钮 | 切换「仅看收藏」过滤，再次点击恢复全部 |
| 8 | 发送消息 | 输入框输入文本 → 按 `Enter` 或点击「发送」 | 流式显示 AI 回答，期间输入框禁用 |
| 9 | 换行输入 | 按 `Shift + Enter` | 输入框内换行，不触发发送 |
| 10 | 停止生成 | 流式输出期间点击「停止」按钮 | 调用 `AbortController.abort()` 立即中断，已生成内容保留 |
| 11 | 上传图片 | 点击输入框左侧 📷 按钮 / 粘贴图片 / 拖拽图片到输入区 | 转 base64 data URL，预览缩略图，发送时附带 |
| 12 | 消息撤回 | 已送达的用户消息下方「撤回」按钮 | 仅 2 分钟内可撤回，撤回后显示「消息已撤回」占位 |
| 13 | 重试失败消息 | 失败用户消息下方「发送失败 · 重试」按钮 | 移除旧失败消息，原文本与图片填回输入框，重新发送 |
| 14 | 复制代码 | AI 回答中代码块右上角「复制」按钮 | 复制纯文本到剪贴板，2 秒内显示「已复制」 |
| 15 | 星级评分 | AI 消息底部 1-5 星 Rate 组件 | 点击星级弹出反馈 Modal，可填问题分类与文字说明 |
| 16 | 转人工 | 左侧「立即转人工」按钮 → 二次确认 | 会话状态变更为「已转人工」，发送框禁用 |
| 17 | 启用/禁用工具 | 输入框下方「启用工具调用」复选框 | 关闭后 AI 仅基于知识库回答，不查询实时数据 |
| 18 | 点击推荐问题 | AI 回答底部「您可能还想问」Tag | 直接发送该问题，绕过输入框 |
| 19 | 帮助中心 | 左侧「帮助中心」按钮 | 弹窗显示使用指南/常见问题/快捷键/版本信息 |

## 快捷回复与预设问题

### 引导卡（ChatbotOnboarding）

空会话或首次进入时显示引导卡，包含三部分：

1. **欢迎语**：从配置接口 `GET /api/chatbot/welcome` 获取，未配置时显示默认值「Hi，我是智能客服小蜜，请问有什么可以帮您？」；夜间（22:00-7:00）显示「夜深了，有什么需要帮忙的吗？」；有历史会话显示「欢迎回来！请继续提问或选择下方常见问题」
2. **热门功能卡片**：硬编码 4 张
   - 📖 知识库问答：从项目文档中检索答案
   - 🔧 工具调用：查询任务、评估、配置
   - 🧑‍💼 人工转接：点踩两次或主动触发
   - 🖼️ 图片识别：上传图片让 AI 解析
3. **常见问题入口**：取 FAQ 列表前 5 条（`enabled=true` 且有 `id`），点击直接发送该问题
4. **使用提示**：3 条小贴士
   - Shift+Enter 换行，Enter 发送
   - 拖拽 / 粘贴 / 点击图片按钮上传图片
   - 点赞 / 点踩帮助我们改进回复质量

**关闭与持久化**：点击右上角 ✕ 关闭，状态写入 `localStorage` key `chatbot_onboarding_dismissed='1'`；切换会话时重置关闭状态，让引导卡再次出现。

### 快捷回复 Chip（QuickReplyChips）

输入区上方显示的横向 Chip 列表，数据源为 FAQ 中 `category` 含「快捷」字样的项（如 `快捷` / `快捷回复` / `quick`），最多取 8 条。点击 Chip 后内容填充到输入框（不直接发送，用户可修改后发送）。

**显示条件**：非流式输出状态且 `quickReplies` 非空。前端实现：`frontend/src/pages/Chatbot/components/QuickReplyChips.tsx`。

## 消息撤回机制

### 时间窗

- **2 分钟**：用户消息发送后 2 分钟内（`Date.now() - created_at < 120000` 毫秒）可撤回
- **超时处理**：超过 2 分钟后「撤回」按钮自动隐藏，无法撤回
- **后端校验**：后端接口 `POST /api/chatbot/messages/{message_id}/recall` 同样校验时间窗，超时返回错误

### 撤回操作步骤

1. 鼠标悬停在自己发送的已送达用户消息上
2. 消息下方出现「撤回」按钮（仅在 2 分钟内、未撤回、已保存到 DB 时显示）
3. 点击「撤回」按钮
4. 前端乐观更新：立即将该消息标记为已撤回，渲染灰色「消息已撤回」占位
5. 调用后端接口，失败时提示「撤回失败，可能已超过 2 分钟时限」

### 撤回后效果

- **用户侧**：原消息内容替换为「消息已撤回」灰色文字
- **AI 侧**：撤回的用户消息不再被纳入后续对话的上下文，AI 不会引用该内容
- **会话历史**：撤回标记保留在数据库 `chatbot_messages.is_recalled=1`，不会物理删除

> 撤回条件：仅用户消息可撤回；AI 回答不可撤回。临时消息（id 以 `temp-` 开头）不显示撤回按钮，需等待消息保存到 DB 后才能撤回。

## 多模态对话

### 图片上传限制

| 限制项 | 上限 | 超出处理 |
|--------|------|----------|
| 单次最多图片数 | 4 张 | 第 5 张起跳过，提示「最多 4 张图片」 |
| 单张大小 | 5 MB | 超过 5MB 跳过，提示「{文件名} 超过 5MB，已跳过」 |
| 接受格式 | `image/*`（所有图片类型） | 非图片文件被 `filter` 过滤，不上传 |

### 三种上传方式

1. **点击上传**：点击输入框左侧 📷 按钮，选择本地图片文件
2. **粘贴上传**：在输入框内 `Ctrl+V` 粘贴图片（自动拦截 `paste` 事件提取 `image/*` 项）
3. **拖拽上传**：将图片文件拖拽到输入区，监听 `drop` 事件提取文件列表

### 图片处理流程

1. 选择图片后调用 `FileReader.readAsDataURL` 转为 base64 data URL
2. 加入 `pendingImages` 列表，在输入框上方显示预览缩略图（含删除按钮 ✕）
3. 发送消息时，图片以 `images` 字段（string 数组）附带在用户消息中
4. AI 消息气泡渲染时，用户消息内显示图片缩略图（点击新窗口打开）
5. 发送完成后清空 `pendingImages`

> 拖拽落点不需要 `role=button`，HTML5 拖拽 API 天然支持 `div` 作为 dropzone。

## 工具调用

智能客服内置 5 个工具，启用「工具调用」复选框后，AI 在回答过程中可主动调用工具查询实时数据。工具调用过程对用户透明，前端显示「工具调用 N 次」标签。

### 工具清单

| 工具名 | 触发场景示例 | 权限 | 超时 | 类型 |
|--------|-------------|------|------|------|
| `get_task_status` | 「我的任务跑了吗」「最近任务状态如何」 | read | 5s | 本地工具 |
| `get_eval_score` | 「这个商品评分多少」「任务 X 的评估结果」 | read | 5s | 本地工具 |
| `get_config_value` | 「现在的评估阈值是多少」「AI 预算怎么配」 | read | 5s | 本地工具 |
| `get_error_logs` | 「最近报什么错」「日志里有什么异常」 | read | 5s | 本地工具 |
| `search_help` | 「帮助文档有哪些章节」「使用说明在哪里」 | read | 10s | LLM 工具 |

### 工具调用流程

1. 用户提问后，AI 先走 RAG 检索知识库
2. 触发机制由 `tool_trigger_mode` 配置控制：
   - `function_calling`（默认）：将工具定义与问题一起发给 LLM，由 LLM 决定是否调用
   - `fallback`：RAG 检索相似度全部低于阈值或回答含「未找到」时自动触发
3. 工具调用结果注入上下文，AI 基于检索 + 工具结果生成最终回答
4. 最多调用 3 轮（可配置 `max_tool_rounds`），避免无限循环
5. 前端 SSE 收到 `tool_call` 事件后追加显示

### 敏感字段过滤

- `get_config_value` / `get_error_logs` 强制脱敏：
  - 黑名单字段（`api_key` / `openai_api_key` / `cookie` / `token` / `password` / `secret` / `webhook_url`）返回 `<REDACTED>`
  - `get_error_logs` 隐藏文件绝对路径与堆栈详情，仅保留错误类型 + 消息
- 过滤逻辑在工具层实现，不依赖 LLM 自觉

## 转人工流程

### 触发条件（5 类，任一满足即触发）

| 序号 | 触发条件 | 默认参数 | 说明 |
|------|---------|----------|------|
| 1 | 用户主动请求 | 关键词：「人工」「客服」「管理员」「转人工」「真人」 | 消息含任一关键词即触发 |
| 2 | 连续点踩 | `feedback_threshold=2` 次，`feedback_window_min=30` 分钟 | 30 分钟内累计 N 次负反馈（1-3 星）触发 |
| 3 | RAG 无匹配 | 相似度阈值 `0.65` | 所有检索片段相似度低于阈值时触发 |
| 4 | AGENT 失败 | `max_tool_rounds=3` 轮 | 多轮工具调用后仍无法回答时触发 |
| 5 | 预算超限 | AI 预算用尽 | Orchestrator 直接转人工，不进入 RAG/AGENT |

> 另有「主动转人工」入口：左侧「立即转人工」按钮，不受上述 5 类条件限制，用户可随时主动触发。点击后弹出确认 Modal「将转接至人工客服，当前会话状态会变更为已转人工。是否继续？」，确认后会话状态变为 `escalated`。

### 转人工卡片

触发转人工后，AI 回答位置显示橙色 Alert 警告卡片：

- **标题**：「已转人工客服」
- **描述**：触发原因（如「连续 2 次点踩」「RAG 无匹配」等）或默认「请联系管理员处理」
- **操作按钮**：「复制会话记录」按钮，点击调用 `GET /api/chatbot/escalation/{session_id}/export`，将脱敏后的会话内容复制到剪贴板

### 联系方式

- 配置项 `escalation.contact` 可填入联系方式（如「QQ群 123456」「GitHub Issues: https://...」）
- 联系方式为空时显示「请联系管理员处理」
- 配置页 `/config/chatbot` → 「转人工」Tab 可设置联系方式，热更新立即生效

### 转人工后会话状态

- 会话状态变为 `escalated`，在列表中显示「已转人工」橙色标签
- 输入框被禁用，placeholder 显示「当前会话已转人工，请创建新会话继续咨询」
- 继续提问会被前端拦截，提示「当前会话已转人工，请创建新会话继续咨询」
- 历史消息仍可查看，但不可继续对话
- 转人工时复制的会话记录自动脱敏：移除 API Key、Cookie、Token 等敏感信息（受 `escalation.sanitize_pii` 配置控制）

## 知识库管理

知识库（KB）管理分两个入口：**KBStatusCard**（配置页「知识库管理」Tab 内，展示状态与重建）与 **VectorAdminPanel**（配置页「向量库维护」Tab，深度维护）。

### KBStatusCard 状态信息

| 字段 | 说明 |
|------|------|
| 当前版本 | 8 位版本号 Tag（绿色=已构建，灰色=未构建） |
| 片段数量 | 知识库切片总数 |
| 最后构建 | 最后一次构建时间，未构建时显示「从未构建」 |
| 状态标签 | `corrupted`=知识库损坏需人工修复（红），`partial`=部分片段构建失败（橙） |
| 重建按钮 | 右上角「重建」按钮，二次确认后异步重建，期间显示进度条 |

**KB 状态值**：`empty`（无版本）/ `success`（成功）/ `partial`（部分失败）/ `failed`（构建失败）/ `building`（构建中）/ `corrupted`（损坏）

### VectorAdminPanel 维护操作

位置：配置页 `/config/chatbot` → 「向量库维护」Tab。前端实现：`frontend/src/pages/Chatbot/components/VectorAdminPanel.tsx`。

**1. 状态总览卡片**：

| 字段 | 说明 |
|------|------|
| 集合名 | ChromaDB 集合名称 |

## 常见问题 FAQ

**Q1：AI 不回答闲鱼平台问题吗？**
A：是的。智能客服严格限定在闲鱼猎人系统使用咨询范围内，闲鱼平台规则（如「闲鱼怎么退款」）、其他产品（如「转转怎么用」）、闲聊（如「今天天气」）等超范围问题会被拒绝，并提示「我是闲鱼猎人系统的智能客服，仅能回答与本系统使用相关的问题」。如需其他帮助可点击「转人工」。

**Q2：撤回超过 2 分钟怎么办？**
A：超过 2 分钟后「撤回」按钮自动隐藏，无法撤回。这是设计约束（与微信等聊天工具一致），2 分钟足够用户发现误发并撤回。如内容已影响后续对话，建议新建会话重新提问。

**Q3：工具调用是什么？**
A：工具调用是 AI 在回答过程中主动查询系统实时数据的能力。启用后，AI 可调用 5 个内置工具（任务状态、评估分数、配置值、错误日志、帮助文档）查询数据库内容并注入回答。例如问「我的任务跑了吗」时，AI 会调用 `get_task_status` 工具查询任务运行状态。如不希望 AI 查询实时数据，可取消勾选输入框下方「启用工具调用」复选框。

**Q4：转人工后怎么办？**
A：会话状态变为「已转人工」后，输入框被禁用，无法继续提问。请：①点击转人工卡片中的「复制会话记录」按钮，将脱敏后的会话内容复制到剪贴板；②按配置的联系方式（如 QQ 群、GitHub Issues）联系人工支持，并粘贴会话记录；③如需继续咨询 AI，请新建会话。

**Q5：知识库多久更新一次？**
A：默认每 6 小时（可配置 `kb.update_interval_hours`，范围 1-168 小时）自动检测 `docs/` 目录变更，变更文件触发增量向量化。也可在配置页「知识库管理」Tab 内点击「重建」按钮手动触发全量重建。重建期间对话功能使用旧版本知识库。

**Q6：图片发不出去怎么办？**
A：检查以下几点：①单张图片不超过 5MB，超过会被跳过并提示；②最多 4 张，超过会被跳过并提示「最多 4 张图片」；③仅接受 `image/*` 类型文件；④流式输出期间上传按钮被禁用，需等待当前回答完成。如仍发不出，尝试刷新页面后重试。

**Q7：会话能保留多久？**
A：会话永久保留在 SQLite 数据库，直到用户主动删除。30 分钟（可配置 `session_timeout_min`）无活动后会话状态自动标记为「已结束」，已结束会话历史仍可查看但不可继续对话，需新建会话。收藏的会话不会因超时而丢失，仅状态变更。

**Q8：为什么有时候回答很慢？**
A：回答速度受多因素影响：①LLM 服务（OpenAI API）响应时间，首 token 通常 ≤ 2 秒，完整 2000 token 回答 ≤ 15 秒；②工具调用轮数（最多 3 轮，每轮本地工具 ≤ 2 秒、LLM 工具 ≤ 10 秒）；③知识库检索耗时（通常 ≤ 500ms）；④网络状况。如长期偏慢，可在配置页降低 `max_tool_rounds` 或关闭工具调用。

**Q9：可以禁用工具调用吗？**
A：可以。两种方式：①对话页输入框下方取消勾选「启用工具调用」复选框（仅当前会话生效，下次进入恢复默认）；②配置页「AGENT 工具」Tab 关闭「启用工具」开关（全局生效，需重启）。关闭后 AI 仅基于知识库回答，不查询实时数据。

**Q10：AI 回答不准确怎么办？**
A：①点击 AI 消息底部 1-3 星评分，弹出反馈 Modal 选择问题类型（答非所问/信息有误/其他）并填写文字反馈；②连续 2 次低分会自动触发转人工；③在配置页「FAQ 管理」补充相关问答；④在「知识库管理」点击「重建」刷新知识库内容；⑤点击回答底部「参考来源」展开，核对引用的文档片段是否相关。

**Q11：参考来源的相似度百分比是什么意思？**
A：相似度百分比表示检索到的文档片段与用户问题的语义相关程度（基于向量余弦相似度计算）。100% 表示完全相关，0% 表示完全无关。低于 65% 的片段通常不会出现在结果中（受 `rag.similarity_threshold` 配置控制），可在配置页调整阈值。

**Q12：会话能搜索消息内容吗？**
A：可以。左侧搜索框输入关键词后会搜索会话标题与消息内容，匹配的会话会显示在列表中。搜索历史会以小药丸形式记录在搜索框下方，点击可快速复用关键词，也可点击「清空」清除历史。

**Q13：转人工时复制的会话记录包含敏感信息吗？**
A：不包含。复制会话记录时自动脱敏，移除 API Key、Cookie、Token 等敏感字段（受 `escalation.sanitize_pii` 配置控制，默认开启）。配置页「转人工」Tab 可查看或修改此设置。

**Q14：知识库能回滚到旧版本吗？**
A：可以。配置页「知识库管理」Tab 内的版本表展示历史版本，点击非当前版本的「回滚」按钮，二次确认后异步回滚。回滚期间对话功能短暂不可用，完成后基于旧版本内容回答。每个版本保留快照，最多保留 10 个（可配置 `snapshot_max_keep`）。

**Q15：引导卡关掉了还能再显示吗？**
A：可以。引导卡的关闭状态保存在 `localStorage`，切换会话时会自动重置关闭状态，让新会话能再次显示引导卡。如希望永久关闭，需清除 `localStorage` 的 `chatbot_onboarding_dismissed` 键或在配置页设置 `welcome_show_onboarding=false`。
