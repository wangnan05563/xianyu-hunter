# 移动端判定诊断脚本

请在浏览器 **F12 Console** 中执行以下 JavaScript，诊断是否被判定为移动端：

```javascript
(function() {
  const ua = navigator.userAgent;
  const w = window.innerWidth;
  const h = window.innerHeight;
  const MOBILE_UA_PATTERN = /Android|webOS|iPhone|iPad|iPod|BlackBerry|IEMobile|Opera Mini/i;
  const isMobileUA = MOBILE_UA_PATTERN.test(ua) || (/Macintosh/i.test(ua) && 'ontouchend' in document);
  const isMobileViewport = w <= 600;
  const detectMobile = isMobileUA || isMobileViewport;
  const pathname = location.pathname;
  
  console.log('=== 移动端判定诊断 ===');
  console.log('User-Agent:', ua);
  console.log('视口宽度:', w + 'px');
  console.log('视口高度:', h + 'px);
  console.log('pathname:', pathname);
  console.log('isMobileUA:', isMobileUA);
  console.log('isMobileViewport:', isMobileViewport);
  console.log('detectMobile:', detectMobile);
  console.log('预期路由:', detectMobile ? '/app/m/' : '/app/');
  
  if (detectMobile && pathname !== '/app/m/' && pathname !== '/app/login') {
    console.warn('⚠️ 应跳转到 /app/m/ 但当前在', pathname);
  }
  
  if (!detectMobile && pathname.startsWith('/app/m')) {
    console.warn('⚠️ 桌面端但当前在移动端路由', pathname);
  }
})();
```

**执行后请把 Console 输出的内容截图或复制给我**，我据此判断：

- 如果 `detectMobile=true`：说明你的浏览器被判定为移动端（UA 或视口宽度触发）
- 如果 `detectMobile=false` 但 URL 是 `/app/m/`：说明浏览器缓存了旧版 SPA（需清除 SW）
