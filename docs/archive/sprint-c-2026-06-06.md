## 7. UX-11 Toast 失败原因持久化

### 7.1 现状问题
- 所有 toast 3.5s 自动消失，err 级信息也丢
- 用户来不及看清/复制就消失了，调试 / 排障时尤其痛苦

### 7.2 实施细节
**前端** [base.html](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/web/templates/base.html) + [onboarding.html](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/web/templates/onboarding.html) + [app.css](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/web/static/app.css)：

**Toast 行为升级**：
- `err` 级 → 永不自动消失；`ok` / `warn` 级 → 3.5s 自动消失
- err / warn 加 `📋 复制` 按钮（用 `navigator.clipboard.writeText` + 兜底选中文本）
- 全部加 `×` 关闭按钮

**全局 `xhToast()` 函数**（抽全局的原因）：
- Alpine 子组件（如 dashboard()）的 `this.toast` 走 scope chain 找父级，onboarding 页面无 appState → 走 `window.xhToast()` 兜底
- 测试 / 浏览器控制台调试可直接调用

**顶栏 ⚠ 最近错误 入口**：
- 顶栏新增按钮（与通知铃铛并列）
- 关闭 err toast → 消息 + 来源 + 时间戳入 `localStorage[xh.errlog.v1]`
- ⚠ badge 显示未查看数；点击 → 抽屉里可复制 / 删除 / 清空
- FIFO 50 条截断；刷新后视作"已查看"（badge 不重放历史）

**drawer 抽屉组件**（与通知中心解耦）：
- 通知中心存"业务级告警"（订单超时）；本抽屉存"操作级错误"（toast 失败）
- 双 tab 不互相干扰

**`dismissToast()` 桥接函数**：
- DOM 事件回调拿不到 Alpine scope → 用 `window.Alpine.$data()` 反向解析 `<div class="app" x-data>`
- 找不到（onboarding 等无 appState 页面）→ 静默降级

### 7.3 验证
- 端到端测试：[scripts/ux_11_smoke.py](file:///d:/code/otherProjects/17_xianyu/scripts/ux_11_smoke.py)（35 项全通过）
  - 截图：`.ux_11_shots/01_dashboard_initial.png` ~ `07_after_reload.png`
- 回归：[scripts/p1_4_smoke.py](file:///d:/code/otherProjects/17_xianyu/scripts/p1_4_smoke.py) 24 项全过（通知中心 API 不受影响）
- 端到端覆盖：toast 不消失 / 复制按钮 / 关闭入 errlog / badge 累加 / 抽屉打开 / 复制 / 删除 / 清空 / 刷新持久化 / 刷新 badge 不重放

### 7.4 与原 UX-05 的关系
- **UX-05**（P1-4 实施）= 关键 err 升级为通知中心条目（数据库）
- **UX-11**（Sprint C 实施）= 所有 err toast 都可手动落入 localStorage 错误日志（前端）
- 二者互补：业务级（订单超时）走通知中心；操作级（点按钮失败）走错误日志
