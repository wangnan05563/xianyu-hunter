## 1. F-08：日志搜索、标记与导出

### 1.1 搜索与过滤 (`/api/logs/search`)

提供 events 表的结构化搜索能力，填补了此前只支持 SSE 尾部流的空白。

**过滤维度**：
- `q`：大小写不敏感子串匹配 `message` + `payload`
- `level`：`info` / `warn` / `err` / `debug` / `trace`
- `tag`：按 `payload.tags[]` 包含关系过滤
- `task_id`：按任务过滤
- `since_id`：增量查询（与 SSE 回放共用语义）
- `limit` / `offset`：分页

**返回增强**：
- `matched_levels`：命中等级直方图（让用户一眼看到 err/warn 占比）
- `matched_tags`：Top 10 标签分布

**搜索流程**（[api_logs.py#L57-L107](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/web/routes/api_logs.py#L57-L107)）：
1. 用 `list_events()` DB 侧过滤（level / task_id / since_id）拉候选行
2. Python 侧做关键字 + 标签二次过滤
3. 统计直方图
4. 分页截断返回

### 1.2 行级打标签 (`/api/logs/tag` + `/api/logs/export`)

**设计决策**：标签存在 `events.payload` JSON 字段的 `tags` 数组中，**零数据库迁移**。重复打同一标签 = 幂等。

- `POST /api/logs/tag`：给事件打标签（含标签名校验：仅字母/数字/`_`/`-`）
- `GET /api/logs/export`：CSV（Excel 友好）或 `.log`（原始文本）格式导出
- 后端新增 `Repository.get_event()` 和 `Repository.update_event_payload()` 支持（[repository.py](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/infra/repository.py)）

### 1.3 前端界面

双 Tab 布局：`⚡ 实时`（SSE 流） / `🔍 搜索`（结构化查询）

搜索 Tab 包含：关键字输入、等级下拉、标签输入、task_id 输入、搜索/重置按钮、CSV/.log 导出按钮、等级直方图、标签 Top10、分页翻页、行级打标签对话框。

## 2. F-09：任务运行历史

### 2.1 后端 (`/api/tasks/{task_id}/runs`)

**核心理念**：按可配置的时间桶（默认 5 分钟）聚合 events，将离散事件合并为"运行"。

**关键参数**（[api_tasks.py](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/web/routes/api_tasks.py)）：
- `range_hours`：1~720 小时查询窗（默认 168h = 7 天）
- `bucket_seconds`：60~3600 秒桶大小（默认 300s = 5 分钟）
- `idle_gap_seconds`：沉默判定阈值（默认 1800s = 30 分钟）

**返回字段**：
- `total_runs` / `total_events` / `total_hits` / `total_errs`
- `runs[]`：每个桶含 `start`, `end`, `duration_s`, `event_count`, `hit_count`, `err_count`, `warn_count`, `info_count`, `first_event_type`
- `idle_gaps[]`：桶间无事件间隔（> idle_gap_seconds），标注起止时间与持续秒数

### 2.2 前端

任务详情页新增"运行历史"卡片，包含：
- 时间窗切换：24h / 3d / 7d / 30d
- 统计摘要栏：运行次数 + 事件数 + 命中数 + 沉默段数
- 表格：起始时间、持续秒数、事件/命中/错误/警告计数、首事件类型
- 含错误行左侧红边、含命中行左侧金边
- 沉默间隔提示栏：>30 分钟无事件段列表

## 3. F-10：免打扰临时关闭（Snooze）

### 3.1 设计

**问题**：用户进入免打扰时段后想当前紧急告警，只能去修改 YAML → 重启 — 太重。

**方案**：轻量级 in-memory snooze 机制，支持 30/60/120 分钟快捷按钮。
- snooze 期间 `is_suppressed_now()` 返回 `False`，所有告警正常推送
- 到时自动恢复按 YAML 配置
- 不修改 YAML 持久配置（重启进程后回到 YAML）

### 3.2 后端

**NotifierHub**（[hub.py](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/modules/notifier/hub.py)）新增：
- `snooze(minutes)` — 设置临时关闭，返回 `snooze_until` 时间
- `clear_snooze()` — 立即恢复
- `snooze_state()` — 返回 `{active, until_iso, remaining_seconds}`
- `_snooze_active()` — 内部检查 + 过期自动清除

**API**（[api_notifier.py](file:///d:/code/otherProjects/17_xianyu/src/xianyu_hunter/web/routes/api_notifier.py#L125-L165)）：
- `POST /quiet-hours/snooze` — 临时关闭 N 分钟（1-480）
- `DELETE /quiet-hours/snooze` — 立即恢复
- `GET /quiet-hours` 返回值新增 `snooze` 字段

### 3.3 前端

免打扰设置 Modal 中新增"snooze 栏"：
- 未激活：三个快捷按钮（30 分钟 / 1 小时 / 2 小时）
- 激活中：橙色高亮 + 实时倒计时显示 + "立即恢复"按钮
- 1s/次前端倒计时，剩余时间为 0 自动重拉状态
