## §3 F-11 任务模板市场（个人版）（P1 — 新增）

### 实现内容
- **10 个预置模板**：覆盖 5 大品类（相机/游戏/球鞋/票务/数码），每个包含 keyword + 价格区间 + 模式
- **模板市场 Modal**：分类标签（7 个）+ 搜索框 + 卡片网格 + 空状态
- **模板→任务一键复制**：点击模板卡片自动填入"新增任务"表单，可二次微调
- **另存为模板**：任务行操作区增加 💾 按钮，从现有任务保存为私有模板
- **私有模板管理**：私有模板显示删除按钮（hover 显示），预置模板不可删

### 技术方案
- 预置模板：YAML 文件 `data/preset_templates.yaml`（10 条）
- 私有模板：JSON 文件 `data/user_templates.json`（uuid 生成 ID）
- API：`GET /api/templates`（列表+分类过滤）、`POST /api/templates`（保存）、`DELETE /api/templates/{id}`（删除私有）
- 前端：Alpine.js 状态管理 + Modal UI + 卡片网格
