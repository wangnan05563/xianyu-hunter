## Sprint E

**主题**：SSE 重连回放 + 批量操作真实语义 + 回归修复

**核心交付**：
- O-09 SSE 重连回放：浏览器 EventSource 断线重连后，服务端用 Last-Event-ID + URL query 双保险回放漏掉事件（≤1000 条）
- UX-08 任务批量操作真实语义：5 个 action（pause/resume/stop/restart/delete）走 `/api/tasks/batch-control`，stop/delete 走 inline 二次确认
- 修复 2 个 500 错误：`api_stats.py` 用了不存在的 `created_at` 字段（应改 `publish_time`）；`api_logs.py` payload dict 没有 `.lower()`

**关键技术决策**：
- SSE 协议层用浏览器原生 Last-Event-ID（零业务侵入），URL query 兜底覆盖反代丢 header 场景
- 不传 last_id = 新会话 = 不回放（避免首次连接刷屏 1000+ 历史事件）
- 心跳节流 2s → 3s，平衡实时性与控制台噪音
- 批量 stop/delete 复用单任务 `_armConfirm` 状态机，用 `'__batch__'` 作为占位 id
- 单个任务失败不中断整批，返回 successes/failures 列表

**涉及主要文件**：
- 后端：`api_stats.py`（events_stream + since_id/max_event_id）/ `api_tasks.py`（batch-control）/ `api_logs.py`（_payload_text）/ `repository.py`
- 前端模板（已迁移至 React）：原 `base.html`（connectEventStream）/ `tasks/list.html`（batch-confirm-bar）
- 测试：`scripts/o09_smoke.py` / `scripts/ux08_smoke.py`

## Sprint K

**主题**：反爬登录管理 — 会话管理自动启动

**核心交付**：
- O-15 会话管理自动启动：登录/导入/注入成功后自动启动 TokenRenewer 后台续期，无需用户手动点击
- 抽离 `LoginOrchestrator.start_session_default()` 便捷方法，4 个登录入口复用
- 抽出共享 helper `web/services/session_starter.py`（fire-and-forget 调度）
- 前端兜底提示：`session.active == false` 但 `cookie_layers.identity == true` 时显示黄色 Alert

**关键技术决策**：
- fire-and-forget 调度：登录流程在后台线程中运行，`asyncio.ensure_future` 调度到 FastAPI 主事件循环，登录成功返回不被会话启动阻塞
- 失败安全：自动启动失败仅记录 `logger.debug` 级别日志，不影响登录成功返回路径
- `_default_renew_callback` 通过浏览器导航到 `h5.m.taobao.com` 触发续期（导航是用户自然行为，风控压力低于直接调用 `getTimestamp` API）

## Sprint About-Menu

**主题**：「关于」菜单 — 元信息 + 文档资源统一入口

**核心交付**：
- 新增 `/about` 独立路由作为元信息 + 文档资源统一入口
- 后端 2 个端点：`GET /api/about`（版本/构建日期/Git SHA）+ `GET /api/about/check-update`（首版固定 `has_update=False`，无 SSRF 风险）
- 前端 About 页面：BrandCard（品牌卡 + 5 态检查更新按钮）+ AboutMenuList（8 项外部链接）+ OpenSourceLicenses（21 前端 + 20 后端依赖清单 Modal）
- MainLayout 6 处微调：侧栏底部独立分组 + 面包屑映射 + Command Palette + g+a 快捷键 + Header 按钮
- Swagger UI 顶栏按钮：「📖 帮助文档」→「📖 关于」，跳 `/app/about`

**关键技术决策**：
- `_safe_build_info()` 三层兜底（try/except + getattr），缺字段返回 `"unknown"`，绝不返回 5xx
- `include_in_schema=False` 从 OpenAPI schema 隐藏，减少 `/openapi.json` 噪声
- `PUBLIC_PREFIXES` 用 startswith 前缀匹配，`/api/about` 单条覆盖两个端点
- `useUpdateChecker` 状态机 5 态：`idle → loading → (latest | newer | error)`，latest 态 3s 后自动回 idle
- `check-update` 首版不发起外网请求，UI 始终显示"已是最新"；后续可改 GitHub Releases API（注意 SSRF 防护）
- `_build_info.py` 仅在执行 `重新构建.bat` 时刷新，开发态可接受读到上一次构建元信息

- 后端新增：`src/xianyu_hunter/web/routes/api_about.py` / `scripts/build_info.py` / `src/xianyu_hunter/_build_info.py`（构建时自动生成）
