# xianyu-automation-startserver
基于提供的 `d:\code\otherProjects\17_xianyu\scripts\启动服务.bat` 、 `d:\code\otherProjects\17_xianyu\scripts\停止服务.bat` 和 `d:\code\otherProjects\17_xianyu\scripts\重新构建.bat` 脚本文件，开发一个名为"xianyu-automation-startserver"的自动化技能。该技能应实现闲鱼猎人项目的自动启动功能，具体包括以下要求：
1. 整合三个脚本文件的功能，实现项目的启动、停止和重新构建的自动化流程
2. 确保技能能够按正确顺序调用相关脚本，处理可能的依赖关系
3. 实现错误处理机制，当某个步骤失败时能够给出明确提示并适当回滚
4. 添加日志记录功能，记录每次操作的时间、执行步骤和结果
5. 提供简洁的用户交互界面或命令行接口，允许用户触发自动化流程
6. 确保技能在Windows环境下能够稳定运行，兼容脚本文件的路径格式
7. 实现启动前的环境检查，验证必要的依赖和配置是否就绪
