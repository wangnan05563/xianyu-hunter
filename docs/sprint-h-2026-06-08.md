## §1 F-08 日志搜索/标记/导出（P1）

### 实现内容
- **搜索 API**：`GET /api/logs/search` 支持关键词 + level + stage + task_id + tag + 时间范围过滤
- **标签系统**：`POST /api/logs/{id}/tag` 打标签 + `DELETE /api/logs/tag` 删标签，标签存储在 event payload.tags 数组
- **导出功能**：`GET /api/logs/export` 支持 .log 和 .csv 格式，带过滤条件导出
- **前端 UI**：搜索栏 + level 下拉 + 时间范围快捷选择（1h/6h/24h/7d）+ 标签药丸 + 导出按钮

## §2 F-09 任务运行历史 Tab（P1）

### 实现内容
- **运行历史 API**：`GET /api/tasks/{task_id}/runs` 按 5min 时间桶聚合 events
- **聚合统计**：每个桶的 event_count / hit_count / err_count / warn_count / duration_s
- **沉默间隔检测**：idle_gaps 数组标识连续无事件时段
- **前端 UI**：detail.html 运行历史 Tab + 24h/3d/7d/30d 时间范围 + 运行历史表格 + 沉默间隔提示

## §3 F-06 AI 多模态成色评估（P1）

### 实现内容
- **Vision API 调用**：`POST /api/ai/evaluate-condition` 调用 GPT-4o 分析商品图片+描述
- **规则模拟 fallback**：无 LLM Key 时基于关键词+价格规则评估，保证开箱可用
- **结果缓存**：评估结果写入 evaluations 表 dimension_scores.ai_condition_eval，避免重复调用
- **前端 UI**：AI 批量评估按钮 + 单条评估按钮 + 推荐/谨慎标签 + 成色评分 + 风险信号 + 详细分析折叠
