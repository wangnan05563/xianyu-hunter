## 1. 设计目标与原则

### 1.1 设计目标

把需求规格 §1.2 的 G1~G5 落地为可指导编码的技术方案，回答"模块怎么分、接口怎么定、数据怎么存、状态怎么流转"。

### 1.2 设计原则

| 原则 | 含义 | 反例 |
|---|---|---|
| **最小入侵** | 现有 11 个业务页面零改动；MainLayout 仅追加 1 个图标按钮 + 1 个提示条 | ❌ 重写 MainLayout |
| **单一事实源** | `permission_registry.yaml` 是功能点 → 权限的唯一映射，前后端共享 | ❌ 在代码里硬编码权限判断 |
| **两段解耦** | 客户端不直接读微信商户密钥；云端不感知客户端 UI 状态 | ❌ 客户端调微信 API |
| **可灰度** | 套餐、定价、优惠码全部走数据库 + `is_active` 开关，可单独上下架 | ❌ 改代码上线新套餐 |
| **可回滚** | 定价版本化 + 授权事件流水；任何变更可回溯 | ❌ 直接 UPDATE 价格 |
| **沿用现有约束** | `hmac.compare_digest`、JSON 错误体、白名单等约束逐条落实 | ❌ 引入新的 token 比对方式 |

### 1.3 非目标（再次明确）

- ❌ 不做反逆向 / 反盗版追踪
- ❌ 不做 RSA 签名（首版 HS256 即可，密钥仅云端持有）
- ❌ 不做微服务化（云端单进程 FastAPI）
- ❌ 不做自动化退款（首版人工审核）

### 3.2 关键类与接口

#### 3.2.1 `MachineCodeCollector`

```python
class MachineCodeCollector:
    """采集硬件指纹并生成 32 位机器码。

    设计：仅在 Windows 上保证稳定；非 Windows 降级到 MAC+username，
    避免开发/测试环境报错。
    """

    def collect(self) -> dict:
        """返回原始硬件字段（用于排障），不直接外泄。"""

    def get_machine_code(self) -> str:
        """返回 sha256(主板序列号 + CPU ID + 磁盘序列号 + MAC)[:32].upper()。

        任何字段采集失败，使用占位符 "<missing>"，避免哈希值变化。
        """
```

#### 3.2.2 `LicenseCache`

```python
class LicenseCache:
    """本地授权缓存：内存 + AES-256 落盘双写。

    设计：JWT 是客户端唯一持有的凭证，必须加密落盘。
    密钥派生自机器码（PBKDF2-HMAC-SHA256, 100000 轮），
    保证换机后即使复制文件也无法解密。
    """

    def load(self) -> Optional[LicenseInfo]:
        """从 license_cache.json 解密加载；失败返回 None。"""

    def save(self, jwt_token: str, plan: str, expire_at: datetime) -> None:
        """AES-256 加密后落盘 + 更新内存。"""

    def clear(self) -> None:
        """撤销时清空缓存。"""

    def is_stale(self) -> bool:
        """JWT 是否超过 72h 需要回源刷新。"""
```

#### 3.2.4 `PermissionChecker`

```python
class PermissionChecker:
    """业务层权限校验：组合 cache + client + registry。

    设计：本地缓存命中时同步返回；缓存失效或超时则异步刷新，
    本次请求按"宽限策略"放行，避免阻塞主流程。
    """

    def __init__(self, cache: LicenseCache, client: LicenseClient,
                 registry: PermissionRegistry): ...

    def check(self, required: str) -> PermissionResult:
        """检查当前授权是否满足 required 权限。

        返回：
          - PermissionResult.granted = True/False
          - PermissionResult.reason = "active" / "expired" / "insufficient" / "grace_period"
          - PermissionResult.plan = 当前套餐码
        """

    def get_current_plan(self) -> Optional[str]: ...
    def refresh_if_stale(self) -> None: ...
```

```sql
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    machine_code TEXT    NOT NULL UNIQUE,           -- 32 位机器码
```

### 5.1 机器码生成

```python
import hashlib, platform, uuid, subprocess

class MachineCodeCollector:
    def get_machine_code(self) -> str:
        parts = [
            self._get_motherboard_serial(),
            self._get_cpu_id(),
            self._get_disk_serial(),
            self._get_mac_address(),
        ]
        raw = "|".join(parts)
        return hashlib.sha256(raw.encode()).hexdigest()[:32].upper()

    def _get_motherboard_serial(self) -> str:
        if platform.system() != "Windows":
            return "<non-windows>"
        try:
            r = subprocess.check_output(
                ["wmic", "baseboard", "get", "serialnumber"],
                stderr=subprocess.DEVNULL, text=True, timeout=3
            )
            return r.strip().splitlines()[-1].strip()
        except Exception:
            return "<missing>"

    def _get_cpu_id(self) -> str:
        if platform.system() != "Windows":
            return "<non-windows>"
        try:
            r = subprocess.check_output(
                ["wmic", "cpu", "get", "ProcessorId"],
                stderr=subprocess.DEVNULL, text=True, timeout=3
            )
            return r.strip().splitlines()[-1].strip()
        except Exception:
            return "<missing>"

    def _get_disk_serial(self) -> str:
        # 同上，wmic diskdrive get SerialNumber
        ...

    def _get_mac_address(self) -> str:
        return uuid.getnode()  # 返回 int，转 hex
```

> **设计决策**：任何字段采集失败统一用 `"<missing>"` 占位符，避免哈希值因部分字段缺失而剧烈变化（导致重新激活）。代价是同型号硬件可能机器码冲突，但概率极低且可通过用户联系方式区分。

### 5.2 JWT 签发与校验

```python
# 云端 jwt_signer.py
import jwt, secrets
from datetime import datetime, timedelta, timezone

class JwtSigner:
    def __init__(self, secret: str, algorithm: str = "HS256",
                 cache_ttl_hours: int = 72):
        # secret 来自环境变量 LICENSE_JWT_SECRET，每 90 天轮换
        self.secret = secret
        self.algorithm = algorithm
        self.cache_ttl = timedelta(hours=cache_ttl_hours)

    def sign(self, license_code: str, machine_code: str,
             plan_code: str, expire_at: datetime) -> str:
        now = datetime.now(timezone.utc)
        payload = {
            "lic": license_code,
            "mch": machine_code,
            "plan": plan_code,
            "exp": int(expire_at.timestamp()),
            "iat": int(now.timestamp()),
            "jti": secrets.token_urlsafe(16),
            # jwt 自身过期时间 = 缓存 TTL（72h），独立于 license.expire_at
            "jwt_exp": int((now + self.cache_ttl).timestamp()),
        }
        return jwt.encode(payload, self.secret, algorithm=self.algorithm)

    def verify(self, token: str) -> dict:
        return jwt.decode(token, self.secret, algorithms=[self.algorithm])
```

> **设计决策**：JWT 自身过期时间（`jwt_exp`）独立于授权到期日（`exp`）。客户端缓存 72h 后必须回源刷新；授权到期日由云端 `LicenseService.verify` 实时查询 DB 后下发给客户端。

### 5.3 权限校验链（客户端）

```python
class PermissionChecker:
    def check(self, required: str) -> PermissionResult:
        info = self.cache.load()
        if info is None:
            return PermissionResult(granted=False, reason="no_license")

        # 1. 离线宽限期检查
        if self._is_offline_too_long(info):
            if self._within_grace_period(info):
                return PermissionResult(granted=True, reason="grace_period",
                                        plan=info.plan_code)
            return PermissionResult(granted=False, reason="offline_too_long")

        # 2. 授权过期检查
        if datetime.now() > info.expire_at:
            return PermissionResult(granted=False, reason="expired",
                                    plan=info.plan_code)

        # 3. 套餐层级匹配
        if self._plan_satisfies(info.plan_code, required):
            return PermissionResult(granted=True, reason="active",
                                    plan=info.plan_code)

        return PermissionResult(granted=False, reason="insufficient",
                                plan=info.plan_code, required=required)

    def _plan_satisfies(self, current: str, required: str) -> bool:
        # 套餐层级：trial=0 < basic=1 < pro=2 < flagship=3
        levels = {"trial": 0, "basic": 1, "pro": 2, "flagship": 3}
        return levels.get(current, -1) >= levels.get(required, 999)
```

### 5.4 续期/升级计算

```python
# 续期：max(old_expire, now) + period
def calculate_extend_expire(old_expire: datetime, period: str) -> datetime:
    now = datetime.now(timezone.utc)
    base = max(old_expire, now)  # 提前续期不吃亏，过期续期从今天起算
    delta = {"month": timedelta(days=30),
             "quarter": timedelta(days=90),
             "year": timedelta(days=365)}[period]
    return base + delta

# 升级补差价：(新套餐月均价 - 旧套餐月均价) × 剩余月数
def calculate_upgrade_diff(old_plan_monthly: Decimal,
                           new_plan_monthly: Decimal,
                           remaining_days: int) -> Decimal:
    monthly_diff = new_plan_monthly - old_plan_monthly
    if monthly_diff <= 0:
        return Decimal("0")
    return (monthly_diff * Decimal(remaining_days) / Decimal(30)).quantize(
        Decimal("0.01"))
```

```
                超过 10 次拒绝

  1. 检查 used_count < total_quota
  2. 检查单设备使用次数 < per_user_limit
  3. used_count += 1
  4. 写 cloud_coupon_usages

```

## 8. 安全设计

### 8.1 密钥与证书管理

| 密钥 | 存储位置 | 轮换周期 | 用途 |
|---|---|---|---|
| `LICENSE_JWT_SECRET` | 云端环境变量（不入库不入日志） | 90 天 | JWT HS256 签名 |
| 微信商户私钥 | 云端 `/etc/wechat/apiclient_key.pem` | 跟随商户证书 | 微信 API 签名 |
| 微信商户证书 | 云端 `/etc/wechat/apiclient_cert.pem` | 1 年 | 微信 API 双向认证 |
| 客户端 AES 密钥 | 派生自机器码（PBKDF2） | 跟随机器码 | license_cache.json 加密 |
| 管理员密码 | bcrypt 哈希入库 | 强制 90 天改密 | 后台登录 |

### 8.2 防重放与防篡改

- JWT 内嵌 `jti`，云端 Redis 维护已撤销 `jti` 列表 30 天。
- 微信回调走 SHA256-RSA 签名校验 + 商户证书双向认证。
- 订单幂等：`cloud_license_orders.order_no` 唯一索引 + `wechat_transaction_id` 唯一索引。
- 优惠码扣减走 Redis Lua 脚本原子操作。

### 8.3 限频与防刷

| 维度 | 限制 | 实现 |
|---|---|---|
| 单 IP 优惠码校验 | 30 次/小时 | Redis 滑动窗口 |
| 单设备优惠码校验 | 10 次/天 | Redis key + TTL |
| 单 IP 创建订单 | 20 次/小时 | Redis 滑动窗口 |
| 管理员登录失败 | 5 次/15min 锁定 | Redis + DB |

### 8.4 日志脱敏

```python
def mask_jwt(token: str) -> str:
    """日志中只记录 JWT 前 8 位 + 长度。"""
    return f"{token[:8]}***(len={len(token)})"

def mask_secret(s: str) -> str:
    return "***" if s else ""
```

## 11. 风险与决策记录

### 11.1 关键设计决策

| ID | 决策 | 理由 | 替代方案 | 影响 |
|---|---|---|---|---|
| D1 | JWT 用 HS256 而非 RS256 | 单一服务端签发，密钥不外泄；首版简单 | RS256 公私钥分离 | 未来若多服务签发需迁移到 RS256 |
| D2 | 客户端 license_cache.json 用机器码派生 AES 密钥 | 换机无法解密，天然防盗 | DPAPI（仅 Windows） | 跨平台一致性更好 |
| D3 | 云端首版可用 SQLite | 部署简单，单实例足够 | 直接 PostgreSQL | 后续需迁移，但 ORM 抽象层已隔离 |
| D4 | 续期到期日 = max(old_expire, now) + period | 提前续期不吃亏 | now + period | 略增加授权时长，但用户体验更好 |
| D5 | 优惠码扣减走 Redis Lua 脚本 | 原子性 + 高性能 | DB 行锁 | 取消订单时需异步释放 |
| D6 | 权限校验缓存失效时异步刷新 + 本次放行 | 避免阻塞主流程 | 同步阻塞等待 | 短暂宽松窗口（≤ 1 次请求） |
| D7 | 管理员后台首版用 Swagger UI | 节省前端开发成本 | 独立 React 后台 | 体验一般，但 P1 可迭代 |

### 11.2 已识别风险

| 风险 | 等级 | 缓解 |
|---|---|---|
| 微信商户号审核延迟 | 高 | 提前申请；过渡期人工激活 |
| 机器码在虚拟机不稳定 | 中 | 降级策略 + 警告日志 |
| JWT 密钥轮换导致旧 token 失效 | 中 | 轮换期 7 天双密钥共存 |
| 优惠码并发抢用 | 中 | Lua 原子扣减 |
| 云端单点故障 | 中 | 客户端 72h 缓存兜底 |
| 客户端被逆向 | 低 | 不投入重资产反逆向 |
| 套餐定价变更影响历史订单 | 低 | 定价版本化 |
