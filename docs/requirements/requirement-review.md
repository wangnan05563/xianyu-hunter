## 一、项目现状总览

### 1.1 项目定位

XianyuHunter 是一款闲鱼（goofish.com）自动捡漏与抢单个人辅助工具，通过浏览器自动化实现关键词监控、商品评估、自动抢单、多渠道通知的完整闭环。

### 1.2 技术栈

Python 3.14 + FastAPI + Playwright + SQLAlchemy/SQLite + Pydantic + loguru + htmx/Alpine.js

### 1.3 已实现功能规模

- **核心模块**：9 个业务模块（采集/评估/购买/调度/去重/价格/反检测/通知/工作器）
- **Web 路由**：30 个路由文件，覆盖 80+ API 端点
- **数据模型**：9 张数据库表
- **前端页面**：11 个 HTML 模板，含 Dashboard/任务/评估/订单/配置/日志/时间线
- **测试覆盖**：148/148 单元测试 + E2E 联通测试全部通过
- **已实现功能**：60+ 项（详见代码库分析报告）

### 1.4 当前业务目标

| 目标层级 | 目标描述 | 当前状态 |
|----------|----------|----------|
| 核心目标 | 自动监控闲鱼低价商品并抢购 | ✅ 已实现 |
| 安全目标 | 反风控、防封号 | ✅ 基本实现（stealth v2 + WAF 熔断） |
| 体验目标 | Web 可视化管理 | ✅ 已实现（完整 Dashboard） |
| 智能目标 | AI 辅助建任务与成色评估 | ✅ 基础实现（F-01/F-06） |
| 变现目标 | 尚未明确 | ❌ 缺失 |

## 七、关键洞察总结

### 7.1 项目核心优势（应保持）

1. **唯一具备完整自动抢单能力的开源工具** — 这是最大的差异化壁垒
2. **4 维卖家评估模型** — 比竞品的 AI 黑盒判断更透明、可调优
3. **完善的 Web 管理界面** — Dashboard/KPI/时间线/日志，体验领先
4. **WAF 熔断 + stealth v2 双重防护** — 安全性领先
5. **148 测试用例** — 代码质量基础扎实

### 7.2 最紧迫的改进方向

1. **修复 3 个已知 Bug**（P0）— 影响核心功能可用性
2. **Docker 部署**（P1-1）— 降低使用门槛，竞品标配
3. **AI 能力深化**（P1-4）— 竞品核心卖点，本项目最大差距
4. **多账号 + 代理池**（P1-2）— 高频用户刚需，付费转化点

### 7.3 最大变现机会

**Open Core 模式**：以开源免费版引流，Pro 版（¥29/月）提供 AI 深度分析 + 多账号 + 贩子识别等高级功能。目标用户为闲鱼职业捡漏者和小型二手商贩，这类用户对效率工具付费意愿强（竞品"捡漏王"已验证商业需求）。

### 7.4 风险提示

1. **平台合规风险**：闲鱼持续升级反爬策略，工具可能随时失效，需持续维护选择器
2. **账号封禁风险**：多账号/代理池功能需谨慎设计，避免被平台批量封禁
3. **商业化合规**：若走 SaaS 路线，需评估平台 ToS 法律风险，建议 Open Core 模式规避
