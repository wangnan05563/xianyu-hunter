## 一、项目现状总览

### 1.1 项目定位

XianyuHunter 是一款闲鱼（goofish.com）自动捡漏与抢单个人辅助工具，通过浏览器自动化实现关键词监控、商品评估、自动抢单、多渠道通知的完整闭环。

### 1.2 技术栈

- **后端**：Python 3.14 + FastAPI + Playwright + SQLAlchemy/SQLite + Pydantic + loguru
- **前端**：React 18 + TypeScript 5 + Vite 5 + Ant Design 5 + ECharts + @dnd-kit + react-flow-renderer + Zustand + Axios + React Router 6 + vite-plugin-pwa
- **AI**：OpenAI API 兼容（含本地 sentence-transformers BAAI/bge-small-zh-v1.5 向量模型）
- **部署**：Docker + docker-compose（dev/prod/split 三种 profile）

### 1.3 已实现功能规模

- **核心模块**：10 个业务模块（采集/评估/购买/调度/去重/价格/反检测/通知/工作器/Chatbot）
- **Web 路由**：30 个路由文件，覆盖 80+ API 端点
- **数据模型**：9 张数据库表
- **前端页面**：20+ 个 React 页面（含 Dashboard/Tasks/Items/Evaluations/Orders/Timeline/Logs/Config/AntiCrawl/Maintenance/Login/Onboarding/Help/About/Chatbot/MenuAdmin/Export/Notifications/PriceDashboard + 移动端 `/m/*`）
- **测试覆盖**：900+ 测试用例全部通过（含单元测试 + E2E 联通测试 + 跨进程缓存同步回归测试）
- **已实现功能**：90+ 项

### 1.4 当前业务目标

| 目标层级 | 目标描述 | 当前状态 |
|----------|----------|----------|
| 核心目标 | 自动监控闲鱼低价商品并抢购 | ✅ 已实现 |
| 安全目标 | 反风控、防封号 | ✅ 已实现（stealth v2 + WAF 熔断 + Cookie 三层管理 + 跨进程同步） |
| 体验目标 | Web 可视化管理 | ✅ 已实现（React SPA + PWA + 全局快捷键 + Command Palette） |
| 智能目标 | AI 辅助建任务与成色评估 | ✅ 已实现（自然语言建任务 + 深度多模态分析 + Chatbot + 向量库） |
| 变现目标 | Open Core 模式 | ❌ 缺失（无 license key 校验） |

## 五、变现路径分析

### 5.1 变现模式对比

| 模式 | 适用场景 | 优势 | 劣势 | 推荐度 |
|------|---------|------|------|--------|
| **开源 + 付费增值（Open Core）** | 核心开源，高级功能付费 | 社区引流 + 付费转化 | 需明确免费/付费边界 | ★★★★★ |
| **SaaS 订阅** | 云端多租户服务 | 经常性收入、规模化 | 运营成本高、合规风险 | ★★★☆☆ |
| **一次性买断** | 桌面软件授权 | 简单直接 | 收入不可持续 | ★★☆☆☆ |
| **API 计量收费** | 开放平台 | B 端变现 | 需要生态规模 | ★★☆☆☆ |
| **咨询/定制服务** | 企业客户 | 高客单价 | 不可规模化 | ★★☆☆☆ |

- 贩子识别引擎（已实现，可作为付费功能的引流点）

- 价格行情看板（已实现）
- 数据导出（已实现）
- Prompt 在线编辑（已实现）

## 七、关键洞察总结

### 7.1 项目核心优势（应保持）

1. **唯一具备完整自动抢单能力的开源工具** — 这是最大的差异化壁垒
2. **4 维卖家评估模型 + AI 深度多模态分析** — 比竞品的 AI 黑盒判断更透明、可调优
3. **完善的 React SPA 管理界面** — Dashboard/KPI/评估漏斗/时间线/日志/Chatbot/向量库，体验领先
4. **WAF 熔断 + stealth v2 + Cookie 三层管理 + 跨进程同步** — 安全性领先
5. **900+ 测试用例** — 代码质量基础扎实
6. **8 渠道通知 + 免打扰时段** — 通知能力领先
7. **PWA 移动端 + 全局快捷键 + Command Palette** — 体验领先
8. **配置版本管理 + diff + 回滚 + 导入导出** — 配置管理完善
9. **任务依赖（F-16）+ 模板市场（F-11）+ 批量操作** — 任务管理领先
10. **Docker 一键部署** — 部署门槛低

### 7.2 最紧迫的改进方向

1. **WebSocket 实时 IM 监听**（P2-5）— 抢单响应速度突破，与海外 Resell Vault 同档
2. **卖家端功能模块**（P2-1）— 从纯买家工具扩展为买卖双向工具
3. **跨平台监控扩展**（P2-4）— 不依赖单一平台
4. **变现模式落地**（Open Core）— 已实现的高阶功能需加 license key 校验

### 7.3 最大变现机会

**Open Core 模式**：以开源免费版引流，Pro 版（¥29/月）提供 AI 深度分析 + 多账号 + 贩子识别等高级功能。目标用户为闲鱼职业捡漏者和小型二手商贩，这类用户对效率工具付费意愿强（竞品"捡漏王"已验证商业需求）。

> **关键校准**：原文档推荐的首批付费功能（AI 深度多模态分析 / 多账号代理池 / 贩子识别 / 价格行情看板）均已实现，仅需补充 license key 校验机制即可作为 Pro 版付费功能。

### 7.4 风险提示

1. **平台合规风险**：闲鱼持续升级反爬策略，工具可能随时失效，需持续维护选择器
2. **账号封禁风险**：多账号/代理池功能需谨慎设计，避免被平台批量封禁
3. **商业化合规**：若走 SaaS 路线，需评估平台 ToS 法律风险，建议 Open Core 模式规避
4. **WebSocket 协议失效风险**：闲鱼 IM 协议（cv-cat/XianYuApis 逆向）可能随时失效，需保留页面轮询作为降级方案
5. **小红书反爬严格**：跨平台扩展（P2-4）需先调研再实施
