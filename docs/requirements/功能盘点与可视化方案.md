## 1. 功能盘点总览

### 1.1 盘点方法论

本次盘点以**配置点**为最小粒度，对项目所有功能模块进行梳理，识别每个配置点的：
- **当前状态**：已页面化 / 部分页面化 / 仅 API / 仅代码配置
- **可视化程度**：表单 / 滑块 / 拖拽 / 实时预览 / 无
- **目标状态**：期望达到的可视化交互方式

### 1.2 盘点统计

| 状态 | 数量 | 占比 |
|------|------|------|
| 已页面化（表单 / 滑块 / 卡片） | 38 | 83% |
| 部分页面化（说明页 / API+UI） | 4 | 9% |
| 仅代码配置 | 4 | 9% |
| **合计** | **46** | 100% |

**结论**：SPA 重构后绝大多数配置点已具备可视化界面，剩余约 9% 为高阶能力（Stealth 脚本、AI Prompt 模板等），仍以代码或在线编辑器形态提供。

## 3. 可视化配置方案设计

### 3.1 设计原则

1. **所见即所得**：所有配置改动实时预览效果
2. **拖拽优先**：排序、关联、依赖等关系型配置使用拖拽
3. **滑块优先**：数值型配置使用滑块 + 实时反馈
4. **卡片化**：开关型配置使用卡片，状态一目了然
5. **向导式**：复杂配置（如任务创建）使用分步向导
6. **零代码**：消除所有 YAML/JSON 手动编辑场景

### 3.2 交互模式定义

| 交互模式 | 适用场景 | 实现方案 |
|----------|----------|----------|
| 滑块（Slider） | 数值范围、权重 | Ant Design Slider + 实时数值 |
| 拖拽排序（Drag Sort） | 通道顺序、关键词优先级 | `@dnd-kit/sortable` |
| 拖拽连线（Drag Connect） | 任务依赖、关联 | `react-flow-renderer` |
| 卡片选择（Card Select） | 模式、模板、渠道 | 网格卡片 + 选中态 |
| 标签编辑（Tag Editor） | 关键词、排除词 | 自定义 `TagEditor.tsx` |
| 可视化编辑器（Visual Editor） | Cron、时间范围 | 自定义 `CronEditor.tsx` |
| 实时预览（Live Preview） | 价格过滤、评估分布 | ECharts 图表 + 配置联动 |
| 向导（Wizard） | 任务创建、批量配置 | 分步表单 + 进度条 |

## 4. 核心模块可视化设计

### 4.1 任务创建与编辑（已落地）

**交互流程**：向导式 3 步创建

```
Step 1: 基础信息
├── 关键词（TagEditor + 智能联想）
├── 任务名称（自动填充）
└── 任务模式（4 张卡片选择：AUTO/SEMI_AUTO/CONFIRM/NOTIFY_ONLY）

Step 2: 价格与过滤
├── 价格区间（双滑块 + 直方图叠加预览）
├── 闲鱼筛选标签（图标卡片多选）
├── 排除词（TagEditor + 拖拽排序）
└── 地域（省份下拉 + 多选）

Step 3: 调度与依赖
├── Cron 表达式（CronEditor + 下次触发预览）
├── 任务依赖（React Flow 拖拽连线图）
└── 确认创建（实时预览完整配置）
```

**实时预览**：
- 关键词输入时，右侧实时显示闲鱼搜索 URL 预览
- 价格滑块拖动时，直方图上叠加过滤区间
- Cron 编辑时，显示未来 5 次触发时间

**AI 智能建任务入口**：任务编辑器顶部"智能建任务"按钮，调用 `/api/ai/parse-task` 自然语言解析后回填表单。

## 7. 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| SPA 首屏加载慢 | 用户体验 | Vite 代码分割 + 路由懒加载（`lazyRetry`） |
| 拖拽库兼容性 | 交互异常 | dnd-kit 跨浏览器测试 |
| 图表性能 | 大数据量卡顿 | ECharts 增量渲染 + 数据采样 |
| 与旧页面共存 | 路由冲突 | 路由前缀隔离 + 渐进迁移 |
| 认证状态同步 | 登录态丢失 | Axios 拦截器 + 401 自动跳转 |
| PWA 缓存过期 | 用户看到旧版本 | ReloadPrompt 检测更新提示 |
