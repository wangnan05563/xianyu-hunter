# XianyuHunter 市场竞品分析与体验优化建议

> 调研范围：闲鱼/Goofish 自动捡漏赛道 + 国际二手平台监控赛道 + 业内最佳实践对照
> 评估方法：现有功能梳理 → 竞品横评 → 差异化分析 → 新增功能与体验优化建议
> 受众：产品 / 前端 / 后端 / 用户本人

---

## 摘要：5 个核心判断

1. **XianyuHunter 在"自动下单 + 推送确认 + 风控熔断"这条链路上已领先所有开源竞品**——`ai-goofish-monitor` / `shaxiu/XianyuAutoAgent` / `idlefish_xianyu_spider` 均止步于"分析+推送"，未做"拍下"。这构成了核心差异化护城河，应在产品对外介绍中重点突出。
2. **AI 多模态评估差距已补齐**——`api_ai_deep.py` 已实现盗图检测 / 损坏识别 / 一致性校验 / 贩子识别 4 维深度多模态分析，与 `ai-goofish-monitor` 看齐。
3. **自然语言创建任务已落地**——`/api/ai/parse-task` 已实现，用户输入"我想买 95 新 A7M4，预算 1.2w 以内"一键生成任务，与头部竞品持平。
4. **键盘流 / 批量管理 / 数据迁移 3 项能力已补齐**——全局快捷键 + Command Palette（Ctrl/Cmd+K）+ 任务批量操作 + 配置导入导出均已落地，与国际监控工具（Resell Reserve / REPDASH / VintiePlus）持平。
5. **数据可视化已从"分布"层升级为"时间趋势 + 对比基线 + 评估漏斗 + 业务 KPI"四层**——价格趋势对比基线、评估漏斗、业务 KPI 均已实现，决策支持能力显著提升。

## 4. 新增功能建议（按 P0/P1/P2 排序）

> **校准说明**：原文档列出 18 项新增功能（F-01 ~ F-18）+ 15 项优化（O-01 ~ O-15），其中 30 项已实现。本节仅保留未实现项。

### 4.1 P0 优先级（1-2 周内做）

> **历史校准**：原文档 P0 项 9 个（F-01~F-05 + O-01~O-04）已全部实现。本节无新增 P0 项。

### 4.2 P1 优先级（1 个月内做）

#### F-AI1 沉默任务检测 + 推送

- **功能描述**：自动发现"配置后从未触发 / 触发但无命中"的任务，提醒用户清理
- **技术可行性**：⭐⭐⭐⭐ — 每日 cron 扫 `tasks LEFT JOIN events ON task_id AND created_at > 7d` → 推 1 条"以下任务 7 天无活动：xxx [停用 / 调整]"
- **预期用户价值**：用户对"哪些任务还活着"一目了然
- **依赖**：现有 events 表

#### F-CO2 操作审计日志

- **功能描述**：记录"谁 / 何时 / 改了什么配置 / 启停了什么任务"
- **技术可行性**：⭐⭐⭐⭐ — 后端在 `tasks`、`config` 表加 `updated_by` + `audit_log` 表
- **预期用户价值**：误操作可追溯、解决"我刚才是不是改了什么"的疑惑
- **依赖**：MU2 多用户管理已实现

#### F-OB2 配置变更影响追踪

- **功能描述**：调高 pass_score 后，对比"调整前 7 天 vs 调整后 7 天"的通过率
- **技术可行性**：⭐⭐⭐ — 每次配置保存记录"变更前 7 天均值"，30 天后展示对比
- **预期用户价值**：避免"改了反而更差"的情况
- **依赖**：现有 events 表 + 配置版本管理

#### F-EX2 智能通知聚合

- **功能描述**：连续 10 条"评估通过"推送时，合并为 1 条摘要
- **技术可行性**：⭐⭐⭐⭐ — Notifier 加 `aggregation_window_min` 配置 + 摘要模板
- **预期用户价值**：通知渠道不被刷屏
- **依赖**：Notifier Hub 已有渠道适配

#### UX-09 接管 Modal 自动关闭 done 阶段

- **功能描述**：`Orders.tsx` done 阶段 3s 后自动关闭，鼠标移入时清除定时器
- **技术可行性**：⭐⭐⭐⭐⭐ — 0.3 人天
- **预期用户价值**：少 1 次点击 + 不打扰

### 4.3 P2 优先级（迭代中）

#### UX-19 Dashboard 拖拽布局 + 阈值告警

- **功能描述**：用户可拖拽统计卡顺序 + 隐藏不常用的卡 + 配置阈值告警
- **技术可行性**：⭐⭐⭐ — 用 `@dnd-kit`（已在前端依赖中）+ 配置存到 localStorage
- **预期用户价值**：每个用户的 Dashboard 个性化
- **依赖**：无

#### F-CO1 团队共享 Dashboard（可选）

- **功能描述**：硬核用户邀请 1-2 个朋友共用一个 Dashboard（"看今天又捡了什么"）
- **技术可行性**：⭐⭐ — 后端加 `share_token` + read-only 路由
- **预期用户价值**：增加"晒战绩"动力，间接促活
- **依赖**：独立产品规划

#### F-EX3 个人战绩卡（分享图）

- **功能描述**：月底生成"本月捡漏报告"（成功 N 单 / 节省 ¥X / 最高评分 Y）
- **技术可行性**：⭐⭐⭐ — 每月 1 日 cron 生成 HTML 截图，前端可下载或分享
- **预期用户价值**：增加用户成就感与社交传播
- **依赖**：无

### 4.4 v2.0 候选（突破单平台限制）

#### F-18 跨平台比价（小红书 C2C）

- **技术可行性**：⭐ — 每平台独立适配 + 统一数据模型，30+ 人天
- **预期用户价值**：覆盖更广、捡漏概率 +N 倍
- **依赖**：独立产品规划
- **风险**：高（小红书反爬严格）
