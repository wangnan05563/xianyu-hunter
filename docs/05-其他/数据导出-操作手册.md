# 数据导出 使用说明

## 概述

数据导出是闲鱼猎人的离线数据归档入口，将系统运行过程中产生的商品、评估、订单、事件四类业务数据按用户自定义筛选条件导出为 Excel/Numbers 友好的 CSV 文件，便于离线复盘、趋势分析与归档。

- **入口位置**：侧边栏「其他」→「数据导出」
- **菜单图标**：`CloudDownloadOutlined`（云朵下载图标）
- **路由**：`/export`
- **认证要求**：必须登录后访问
- **前端实现**：`frontend/src/pages/Export/index.tsx`

## 核心特性

- **4 类数据集**：商品列表（items）/ 评估记录（evaluations）/ 订单记录（orders）/ 事件日志（events）覆盖主要业务数据
- **UTF-8 BOM 头**：CSV 文件以 UTF-8 BOM 开头，Excel/Numbers/WPS 直接打开中文不乱码
- **完整筛选条件**：任务 ID、时间范围、订单状态、事件等级、行数上限 5 个维度自由组合
- **列定义预览**：进入页面即可看到每个数据集的字段顺序，导出前确认列完整
- **行数上限 1~50000**：默认 5000 行，最大可调至 50000 行
- **与 ExportButton 共存**：业务页工具栏的嵌入式导出按钮仍保留，独立页面提供更完整的筛选
- **浏览器原生下载**：点击导出后由浏览器原生触发文件下载，不占用前端运行时内存

## 基本操作

| 序号 | 操作 | 触发方式 | 说明 |
|------|------|----------|------|
| 1 | 进入数据导出页面（菜单点击） | 侧边栏「其他」→「数据导出」 | 进入 `/export` 页面，自动加载 4 张数据集卡片 |
| 2 | 进入数据导出页面（命令面板） | `Ctrl+K` 打开命令面板 → 输入「数据导出」→ 选中命令 | 同样跳转到 `/export` |
| 3 | 查看 4 个数据集卡片 | 进入页面后默认展示 | 商品列表 / 评估记录 / 订单记录 / 事件日志 4 张卡片两列布局 |
| 4 | 查看列定义预览 | 在每张卡片头部下方查看 Tag 列表 | Tag 顺序即 CSV 实际列顺序 |
| 5 | 填写任务 ID（可选） | 在「任务 ID 过滤（可选）」输入框中输入 | 留空表示不按任务过滤；4 个数据集均支持 |
| 6 | 选择时间范围（可选） | 点击「RangePicker」控件，选择起止时间（含时分秒） | 闭区间，含两端；4 个数据集均支持 |
| 7 | 输入订单状态（仅 orders） | 在订单记录卡片的「订单状态过滤」输入框中输入 | 如 `succeeded` / `failed` / `pending` / `takeover_pending` |
| 8 | 输入事件等级（仅 events） | 在事件日志卡片的「事件等级过滤」输入框中输入 | 如 `info` / `warning` / `error` |
| 9 | 设置行数上限 | 调整「行数上限」InputNumber 控件 | 默认 5000，最小 1，最大 50000；清空自动回退 5000 |
| 10 | 触发导出 | 点击卡片右下角「导出 CSV」主按钮 | 浏览器立即弹出下载，文件名形如 `xh-items-20260705-103045.csv` |
| 11 | 找到下载的文件 | 浏览器下载完成后查看下载目录 | 文件保存在浏览器默认下载路径 |
| 12 | 在 Excel 中打开 | 双击 CSV 文件，选择 Excel 打开 | UTF-8 BOM 头确保中文不乱码，列按预期顺序展示 |

> 点击导出按钮后页面右上角会弹出「正在导出 XX...」提示，告知用户下载已触发。下载完成后由浏览器原生提示，不在页面内反馈成功或失败。

### 卡片结构

每张数据集卡片包含以下区域：

| 区域 | 内容 | 说明 |
|------|------|------|
| 头部 | 主题色图标 + 中文标题 + 数据集 key Tag | 主题色用于快速区分数据集类型 |
| 描述段落 | 数据集简介（来自后端 `_DATASET_DESCRIPTIONS`） | 一句话说明数据集内容 |
| 列定义预览 | 字段名 Tag 列表 | 顺序与 CSV 实际列顺序一致，便于导出前确认字段 |
| 筛选表单 | 依 `DATASET_FILTERS` 显隐控件 | 4 个数据集显隐不同，详见「筛选条件」章节 |
| 操作区 | 行数上限 + 「导出 CSV」主按钮 | 按钮触发浏览器原生下载 |

### 加载态

进入页面时显示 `Spin` 居中加载动画，提示「加载数据集...」。列定义接口拉取失败时使用静态列定义兜底，保证页面仍可渲染。

## 筛选条件

### task_id（任务 ID）

| 项 | 值 |
|---|---|
| 必填 | 否 |
| 控件 | Input（allowClear，size=small） |
| 默认值 | 空 |
| 占位符 | 「任务 ID 过滤（可选）」 |
| 应用数据集 | items / evaluations / orders / events |
| evaluations 特殊处理 | 通过 items 表间接关联（先查 items，再用商品 ID 反查评估） |

留空时不过滤；填写后按任务 ID 精确匹配。点击输入框右侧 × 可一键清空。

### time（时间范围）

| 项 | 值 |
|---|---|
| 必填 | 否 |
| 控件 | DatePicker.RangePicker（showTime，size=small） |
| 默认值 | 空 |
| 时间格式 | `YYYY-MM-DDTHH:mm:ss` |
| 区间类型 | 闭区间（含两端） |
| 时间字段映射 | items=`first_seen` / evaluations=`created_at` / orders=`created_at` / events=`created_at` |

时间范围选择后输出 ISO 格式字符串作为 URL 参数 `start` 与 `end`。两端均包含，即恰好等于边界时间的数据会被保留。

### status（订单状态）

| 项 | 值 |
|---|---|
| 必填 | 否 |
| 控件 | Input（allowClear，size=small） |
| 默认值 | 空 |
| 占位符 | 「订单状态过滤（如 succeeded/failed/pending）」 |
| 仅应用数据集 | orders |
| 取值参考 | `pending` / `takeover_pending` / `succeeded` / `failed` / `cancelled` / `submitting` / `paying` |

留空时返回所有状态的订单。

### level（事件等级）

| 项 | 值 |
|---|---|
| 必填 | 否 |
| 控件 | Input（allowClear，size=small） |
| 默认值 | 空 |
| 占位符 | 「事件等级过滤（如 info/warning/error）」 |
| 仅应用数据集 | events |
| 取值参考 | `info` / `warning` / `error` |

留空时返回所有等级的事件。

### limit（行数上限）

| 项 | 值 |
|---|---|
| 必填 | 否 |
| 控件 | InputNumber（min=1，max=50000，width=100） |
| 默认值 | 5000 |
| 应用数据集 | items / evaluations / orders / events |
| 空值回退 | 前端清空时回退 5000 |
| 超出范围 | 前端 InputNumber 限制输入，后端兜底返回 422 |

行数上限为导出最大行数，超过此值的数据不会写入 CSV。如需更大批量，建议按时间范围分多次导出。

## DATASET_FILTERS 筛选字段矩阵

| 数据集 | task_id | time | status | level | limit |
|---|---|---|---|---|---|
| items | ✅ | ✅ | ❌ | ❌ | ✅ |
| evaluations | ✅（通过 items 间接） | ✅ | ❌ | ❌ | ✅ |
| orders | ✅ | ✅ | ✅ | ❌ | ✅ |
| events | ✅ | ✅ | ❌ | ✅ | ✅ |

**说明**：

- `task_id` 与 `limit` 4 个数据集全部支持
- `time` 4 个数据集全部支持，分别按 `first_seen`（items）/ `created_at`（其余 3 个）过滤
- `status` 仅 orders 卡片显示该输入框
- `level` 仅 events 卡片显示该输入框
- 前端按矩阵显隐筛选控件，未支持的字段不会出现在对应卡片的表单中

## 导出文件规范

### 文件命名

- **规则**：`xh-{dataset}-{YYYYMMDD-HHMMSS}.csv`
- **示例**：`xh-items-20260705-103045.csv`
- **时间戳来源**：服务端导出时刻
- **作用**：避免覆盖同名文件，便于按时间排序查找

### 编码

| 项 | 值 |
|---|---|
| 字符编码 | UTF-8 |
| BOM 头 | `\ufeff`（写入文件开头） |
| 媒体类型 | `text/csv; charset=utf-8` |
| 兼容性 | Excel / Numbers / WPS / Google Sheets |

> **为什么需要 BOM**：Excel 默认按 GBK 解析 CSV，无 BOM 时中文会乱码。Numbers 与 WPS 同样依赖 BOM 识别 UTF-8。

### 空值处理

| 情况 | CSV 单元格内容 |
|---|---|
| 字段缺失 | 空字符串（`""`） |
| 字段为 `None` | 空字符串（`""`） |
| 字段为 `0` / `False` | 原值（`0` / `False`） |
| 时间字段为 `None` | 空字符串 |
| 整行被时间过滤跳过 | 不写入 |

### 列顺序

列顺序由后端 `_DATASET_COLUMNS` 字典定义，**与代码中数组顺序完全一致**，不按字母重排。前端列定义预览接口返回的顺序就是 CSV 实际列顺序。

### 空数据导出

查询结果为空时，CSV 仅包含表头一行（无数据行），仍返回 200 OK 并触发下载。用户可看到只有表头的 CSV，明确知道「无符合条件的数据」。

## 导出流程

从用户视角的完整导出步骤：

1. **进入页面**：侧边栏「其他」→「数据导出」，或 `Ctrl+K` 命令面板搜索「数据导出」
2. **查看卡片**：页面渲染 4 张数据集卡片，加载完成后展示列定义 Tag
3. **选择目标数据集卡片**：找到要导出的数据集（如「订单记录」）
4. **填写筛选条件**：
   - 在「任务 ID 过滤」输入框中输入任务 ID（可选）
   - 点击「RangePicker」选择时间范围（可选）
   - 在「订单状态过滤」输入框中输入 `failed`（仅 orders 卡片）
   - 调整「行数上限」为 5000（默认值，可改）
5. **点击「导出 CSV」按钮**：
   - 页面右上角弹出「正在导出 订单记录...」提示
   - 浏览器自动触发文件下载
6. **下载完成**：
   - 浏览器原生提示下载完成
   - 文件保存在浏览器默认下载目录
   - 文件名形如 `xh-orders-20260705-103045.csv`
7. **打开 CSV**：
   - 双击文件用 Excel/Numbers/WPS 打开
   - UTF-8 BOM 头确保中文不乱码
   - 列顺序与页面预览的列定义完全一致

> **说明**：导出采用浏览器原生 URL 直跳触发下载，因此下载完成或失败时页面不会再次给出反馈。如下载未触发，请检查浏览器下载设置或后端是否返回错误（详见「常见问题 FAQ」）。

## 与 ExportButton 的对比

闲鱼猎人提供两种导出入口：

### ExportButton（嵌入式按钮）

- **入口**：业务页（商品列表、评估明细）顶部工具栏
- **筛选来源**：调用方传入参数（如当前页选中的 `selectedTask`）
- **列定义预览**：不展示
- **行数上限**：不暴露，使用默认 5000
- **时间范围**：不暴露，由调用方传入
- **数据集切换**：主按钮导出当前数据集，下拉菜单可切换其他 3 个

### 独立 Export 页面（本菜单）

- **入口**：侧边栏「其他」→「数据导出」
- **筛选来源**：用户在页面表单中自由填写
- **列定义预览**：展示 Tag 列表
- **行数上限**：暴露 InputNumber，1~50000 可调
- **时间范围**：暴露 RangePicker（含 showTime）
- **数据集切换**：4 张卡片并列展示，各自独立筛选

### 使用场景建议

| 场景 | 推荐入口 | 原因 |
|------|---------|------|
| 在商品列表页浏览某任务，希望快速导出当前任务数据 | ExportButton | 当前页上下文已确定，一键导出 |
| 在评估明细页查看某任务，希望快速导出当前评估 | ExportButton | 同上 |
| 需要按时间范围、订单状态、事件等级精细筛选 | 独立 Export 页面 | ExportButton 不暴露这些筛选 |
| 需要导出超过 5000 行的数据 | 独立 Export 页面 | ExportButton 不暴露行数上限 |
| 需要预览列定义后再决定是否导出 | 独立 Export 页面 | ExportButton 不展示列定义 |
| 跨数据集批量导出 | 独立 Export 页面 | 4 张卡片并列，便于切换 |

> 两者底层共用 `frontend/src/api/export.ts` 的 `exportApi.download` 方法，最终命中同一后端路由 `GET /api/export/{dataset}`，CSV 生成逻辑完全一致。

> **关于 `g+X` 前缀快捷键**：当前 `G_PREFIX_MAP` 中已分配的快捷键包括 `g+d`（仪表盘）、`g+t`（任务管理）、`g+o`（抢单记录）、`g+e`（卖家评估）、`g+i`（事件时间线）、`g+c`（价格策略）、`g+l`（实时日志）、`g+a`（关于）、`g+m`（智能客服）。**`/export` 路由未分配 `g` 前缀快捷键**，需通过 `Ctrl+K` 命令面板或直接点击侧边栏菜单进入。

## 常见问题 FAQ

**Q1：为什么 CSV 文件在 Excel 里中文乱码？**
A：本系统导出的 CSV 已写入 UTF-8 BOM 头（`\ufeff`），Excel 2016+ 可正确识别。如出现乱码，请检查：1) Excel 版本是否过旧；2) 是否使用其他文本编辑器另存为其他编码后丢失了 BOM；3) 是否通过邮件/IM 工具传输时编码被转换。建议直接用 Excel 打开原始下载文件。

**Q2：行数上限能调到多少？**
A：最小 1，最大 50000，默认 5000。前端 `InputNumber` 与后端校验双重限制，超出范围后端返回 422 校验错误。如需导出超过 50000 行的数据，建议按时间范围分多次导出。

**Q3：为什么 evaluations 按 task_id 过滤时还要查 items 表？**
A：评估记录表本身没有 `task_id` 列（只有 `item_id`），无法直接按任务过滤。系统会先查商品列表得到该任务下的所有商品 ID，再用商品 ID 反查评估记录，所以筛选速度比 items 略慢。

**Q4：能导出 Excel 原生格式（.xlsx）吗？**
A：当前版本仅支持 CSV 格式。CSV + UTF-8 BOM 已能被 Excel/Numbers/WPS 直接打开，且无需引入额外的 .xlsx 生成依赖。后续如需原生 Excel 格式（含格式化、公式等），可考虑增强导出能力。

**Q5：能定时自动导出吗？**
A：当前版本不支持定时导出与导出历史记录。导出为手动触发的同步操作，用户需要进入页面或点击 ExportButton 后立即生成。如需周期性归档，可结合系统定时任务调用后端 `/api/export/{dataset}` 接口实现（不在本菜单范围内）。

**Q6：能自定义选择列吗？**
A：当前版本不支持列自定义。每个数据集的列定义由后端 `_DATASET_COLUMNS` 字典固定，列顺序与代码中数组顺序一致。如需仅导出部分列，可在 Excel 中删除不需要的列。

**Q7：空数据导出会怎样？**
A：查询结果为空时，CSV 仅包含表头一行（无数据行），仍会触发下载。用户可看到只有表头的 CSV，明确知道「无符合条件的数据」。前端不会预先检查行数，避免额外的查询开销。

**Q8：为什么有时浏览器显示错误页？**
A：导出采用浏览器原生 URL 直跳触发下载，无法捕获服务端错误响应。常见原因：1) 登录态过期（401），需重新登录；2) `limit` 超出 1~50000 范围（422）；3) 数据集 key 非法（400，正常使用不会触发）；4) 服务端异常（5xx）。请检查登录状态与筛选条件后重试。

**Q9：ExportButton 和独立页面有什么区别？**
A：`ExportButton` 是嵌入式按钮，挂在业务页工具栏，使用调用方传入的参数（如当前页选中的任务 ID），适合「我正在看 X，导出当前 X」的快速场景；独立 `Export` 页面（`/export`）提供完整筛选表单（task_id / 时间范围 / status / level / limit），适合跨数据集、复杂筛选、大批量导出。两者底层共用同一导出 API 与 CSV 生成逻辑。

**Q10：能按用户隔离导出吗？**
A：当前版本未做用户级数据隔离，所有通过认证的用户均可导出全量数据。本地个人工具场景下，多用户隔离优先级低于功能可用性，故未实现。

**Q11：导出文件名是怎么命名的？**
A：`xh-{dataset}-{YYYYMMDD-HHMMSS}.csv`，例如 `xh-items-20260705-103045.csv`。`dataset` 为数据集 key（items/evaluations/orders/events），时间戳取服务端导出时刻。文件名带时间戳避免覆盖同名文件。

**Q12：导出需要登录吗？**
A：需要。导出接口不在公开白名单中，必须携带有效登录凭证。下载走浏览器原生直跳，仅依赖同源请求自动携带的登录 cookie，因此要求浏览器已登录且 cookie 未过期。

**Q13：登录态过期了怎么办？**
A：若导出时浏览器显示 401 错误页，表示登录态已过期。请回到闲鱼猎人主界面，系统会自动跳转到登录页（带 redirect 参数），重新登录后即可继续操作。

**Q14：导出 CSV 列顺序是怎么定的？**
A：完全由后端 `_DATASET_COLUMNS` 字典中数组的顺序决定，不按字母重排。前端 `GET /api/export` 返回的列顺序就是 CSV 实际列顺序，用户可在导出前在卡片中预览列定义 Tag 列表确认。

**Q15：时间范围的 start 与 end 是开区间还是闭区间？**
A：闭区间（含两端）。即恰好等于起始时间或截止时间的数据会被保留。例如设置 `start=2026-07-05T00:00:00` 与 `end=2026-07-05T23:59:59`，则当日 0 时至 23:59:59 的数据全部包含。

**Q16：4 个数据集的筛选字段有什么区别？**
A：`task_id` 与 `time` 4 个数据集全部支持；`status` 仅 orders 支持；`level` 仅 events 支持。前端按 `DATASET_FILTERS` 矩阵显隐筛选控件，未支持的字段不会出现在对应卡片表单中。详见「DATASET_FILTERS 筛选字段矩阵」章节。
