# 模式 V：UI视觉回归测试

> 配置节点：`config.yaml#mode_v_visual_regression_test`

### 触发关键词
- 测试图标替换 / 验证视觉变更 / UI回归测试
- 图标/主题/布局大面积替换后

### 步骤 0：加载配置
读取 `config.yaml`，重点关注 `mode_v_visual_regression_test` 段。禁止硬编码任何页面路径、截图目录、差异阈值。

### 步骤 1：截图基线
1. 确保服务已用最新代码重启
2. 按 `pages_to_capture` 列表逐页截图并保存为基线文件

### 步骤 2：变更后截图
1. 确认图标/主题/布局变更已部署
2. 重新截图各关键页面

### 步骤 3：对比验证
1. 像素级对比基线与变更后截图
2. 超过 `diff_threshold_percent` 的页面标记为"需关注"
3. 差异分类：预期差异 vs 非预期差异

### 步骤 4：用户确认
1. 展示对比结果给用户
2. 用户确认每个差异是否为预期变更
3. 非预期差异标记为缺陷

### 步骤 5：生成测试报告
输出视觉回归测试报告，包含截图对比与缺陷清单。
