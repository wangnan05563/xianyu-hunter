# 模式 X：状态机完整性测试

> 配置节点：`config.yaml#mode_x_state_machine_test`

### 触发关键词
- 测试状态机 / 验证状态流转 / 测试scheduler状态
- scheduler/session状态流转代码修改后

### 步骤 0：加载配置
读取 `config.yaml` 的 `mode_x_state_machine_test` 段。禁止硬编码任何状态名、转换名、返回值语义。

### 步骤 1：列出所有状态
1. 从源码提取所有状态枚举定义
2. 与配置中的 `states_to_check` 列表对比
3. 标记缺失/多余状态

### 步骤 2：验证每个转换
1. 按 `transitions_to_verify` 列表逐个验证：前置条件、触发、后置条件
2. 验证转换可达性与原子性
3. 检测非法转换是否被拒绝

### 步骤 3：验证异常恢复
1. 模拟 pause 后 resume，验证恢复正确性
2. 模拟连续异常，验证不进入不可恢复状态

### 步骤 4：验证返回值语义
1. 扫描状态机相关方法的返回值
2. 验证 return True/False 与调用方逻辑对齐
3. 标记语义不一致

### 步骤 5：运行单元测试
执行 scheduler 相关 pytest，记录通过/失败。

### 步骤 6：生成测试报告
输出状态枚举、转换、异常恢复、返回值语义的完整验证结果。
