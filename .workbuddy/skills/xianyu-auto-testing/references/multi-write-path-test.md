# 模式 T：多写入路径状态一致性测试

> 配置节点：`config.yaml#mode_t_multi_write_path_test`

### 触发关键词
- 测试多写入路径 / 验证状态一致性 / 测试双写冲突
- API 写入与调度器写入不一致 / DB 状态与实际状态不同步

### 步骤 0：加载配置
读取 `config.yaml` 的 `mode_t_multi_write_path_test` 段。禁止硬编码。

### 步骤 1：多路径定位
1. 识别所有写入同一状态字段的代码路径（API 端点 + 调度器 + 子进程回调）
2. 验证写入逻辑一致（相同的状态值、相同的条件判断）

### 步骤 2：并发写入冲突验证
1. 模拟 API 和调度器同时对同一资源写入
2. 验证最终状态一致性
3. 验证无死锁或 race condition

### 步骤 3：路径间语义一致性
1. 验证各路径对"成功/失败/超时"的语义定义一致
2. 验证 DB 状态、内存缓存、子进程状态三者对齐
