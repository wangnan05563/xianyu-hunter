# 模式 N：登录副作用自动化测试

> 配置节点：`config.yaml#mode_n`

### 触发关键词
- 测试登录副作用 / 验证登录入口 helper 覆盖 / 测试 fire-and-forget 调度
- 登录后副作用未触发 / 登录失败后无兜底提示

### 步骤 0：加载配置
读取 `config.yaml` 的 `mode_n` 段。禁止硬编码。

### 步骤 1：登录入口 helper 覆盖验证
1. 扫描所有登录入口（API 端点 + 调度器自动登录 + 手动登录）
2. 验证每个入口是否调用了登录副作用 helper（如 `_post_login_side_effects`）
3. 标记遗漏的登录入口

### 步骤 2：fire-and-forget 调度验证
1. 验证登录副作用是否使用异步调度（`asyncio.create_task` 或等价方式）
2. 验证副作用失败不阻塞主登录流程
3. 验证超时保护（登录副作用不应无限等待）

### 步骤 3：失败安全验证
1. 模拟登录副作用异常，验证主登录流程仍返回成功
2. 验证副作用异常有完整的日志记录（`logger.exception`）
3. 验证异常不冒泡到用户界面

### 步骤 4：前端兜底提示验证
1. 验证登录后副作用完成时前端有对应提示（如"配置已加载"）
2. 验证副作用失败时前端有兜底提示（如"部分功能可能需要手动刷新"）
3. 禁止静默失败（副作用失败但用户无感知）

### 步骤 5：生成测试报告
输出登录副作用测试报告，包含：
1. **入口覆盖状态**：所有登录入口的 helper 调用情况
2. **调度安全性**：fire-and-forget 是否正确实现
3. **失败安全性**：异常隔离与日志记录
4. **前端提示**：成功/失败两种场景的用户提示完整性
