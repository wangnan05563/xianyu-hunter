# 模式 S：UI 偏好持久化回归测试

> 配置节点：`config.yaml#mode_s_ui_persistence_test`

### 触发关键词
- 测试主题持久化 / 验证布局偏好 / 用户设置保存
- 主题切换不生效 / 页面刷新后偏好丢失 / localStorage 被清空

### 步骤 0：加载配置
读取 `config.yaml` 的 `mode_s_ui_persistence_test` 段。禁止硬编码。

### 步骤 1：主题持久化验证
1. 切换主题（亮色/暗色）
2. 刷新页面，验证主题保持
3. 验证 localStorage 中的主题值持久化

### 步骤 2：布局偏好验证
1. 调整侧边栏展开/折叠
2. 刷新页面，验证布局状态保持
3. 验证跨 Tab 页签偏好一致性

### 步骤 3：重置后默认值验证
1. 清除 localStorage
2. 刷新页面，验证加载默认主题/布局
