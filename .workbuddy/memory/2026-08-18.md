## 完成：Tooltip 功能代码评审 + 两项缺陷修复（TipButton.tsx）

对本次会话新增/改写的 TipButton 组件及 65 文件/~363 处 `<TipButton>` 做结构化评审（4 维度）。确认结论：

### 评审发现（2 项需修，已修复）
1. **[中/偏高] disabled 按钮 Tooltip 不显示**：从 `antd/es/tooltip/index.js:143,188` 确认 antd v5 不为 disabled 子元素包裹 span，浏览器也不向 disabled `<button>` 派发鼠标/触摸事件 → 禁用态提示丢失。精确枚举 **65 处** `<TipButton disabled>`（pages/ 下 20+ 文件，含 Login/Maintenance/Tasks/Config/Items 等高频页）。**修复**：`TipButton` 检测 `rest.disabled === true` 时用 `<span class="xh-tipbtn-disabled-wrap">` 包裹 Button（桌面 hover + 触屏长按均恢复提示；`block` 时 span 设 `display:block;width:100%` 保布局）。
2. **[中/低] 移动端 `longPressed` 残留吞点击**：原 `onTouchStart` 未先把 `longPressed.current` 归位，若长按后浏览器未派发 click（触屏位移等），标志残留 → 下次短按动作被吞。**修复**：`onTouchStart` 起始 `longPressed.current = false`。

### 未发现问题
- 动态 tip 表达式取值：15 处（含 `BatchRefresh` 已修的 `triggerTooltipText`）均合理；`tip` 缺失 0 处。
- 类型安全：`npx tsc --noEmit -p tsconfig.json` 零错误（exit 0）。
- 安全：tip 为受控 ReactNode、无 `dangerouslySetInnerHTML`、无用户自由文本 → 无 XSS/注入/越权/敏感数据暴露面。
- 兼容性：Button→TipButton 替换契约一致；仅 disabled 包裹需注意 `block` 宽度（已处理）。
