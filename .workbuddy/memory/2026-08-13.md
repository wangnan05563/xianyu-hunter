### 实测数据
- 体积：fp32 90.5MB → int8 **54.6MB**（省 35.8MB / 39.6%）。
- 质量：int8 vs fp32 余弦 min=0.9952 / mean=0.9957；top-1 检索一致（量化无感）。
- 等价性：fp32 ONNX vs ST 余弦=1.0（与昨日结论一致）。

### 关键坑（已记入文档 §9.4）
1. `quantize_dynamic` 在 onnxruntime 1.x 已**移除 `optimize_model` 参数**，勿传否则 TypeError。
2. 量化需要 `onnx` 包；`.venv-build` 原缺 onnx，已 `pip install onnx==1.22.0`（build 自包含）。
3. 仅量化 MatMul/Gemm 即得 ~40% 体积收益；Gather（embedding 查表）不量化（易掉点、体量小）。
4. 量化只动权重，CLS pooling + L2 归一化保持 fp32，输出语义不变。

### 备注
